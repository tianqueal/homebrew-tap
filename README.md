# Tianqueal Tap

## How do I install these formulae?

`brew install tianqueal/tap/<formula>`

Or `brew tap tianqueal/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "tianqueal/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
